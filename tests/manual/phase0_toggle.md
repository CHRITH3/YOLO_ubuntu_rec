# Phase 0 手动测试文档

## 测试目标
验证 Phase 0 数据记录开关与会话模型功能的正确性。

## 前置条件
1. 已编译 `yolo_pose_indemind_left` 可执行文件
2. INDEMIND 双目相机已连接
3. 已建立坐标系（点击三次设置原点和坐标轴）

## 测试用例

### TC-01: 录制开关切换
**步骤:**
1. 启动程序: `sudo ./build/yolo_pose_indemind_left`
2. 观察右上角状态面板，确认显示 `REC: OFF`（灰色）
3. 按下 `R` 键
4. 观察控制台输出和状态面板

**预期结果:**
- 控制台输出: `[Session] 新会话已创建: runs/YYYYMMDD_HHMMSS`
- 控制台输出: `[录制] REC: ON`
- 状态面板显示 `REC: ON`（红色）
- `runs/` 目录下创建新的时间戳目录

**验收标准:** [ ] 通过 / [ ] 失败

---

### TC-02: 录制关闭
**步骤:**
1. 在 REC: ON 状态下
2. 按下 `R` 键

**预期结果:**
- 控制台输出: `[录制] REC: OFF`
- 状态面板显示 `REC: OFF`（灰色）

**验收标准:** [ ] 通过 / [ ] 失败

---

### TC-03: 落点检测与计数
**步骤:**
1. 启动程序并建立坐标系
2. 按 `R` 开启录制
3. 在蹦床上进行跳跃动作
4. 观察状态面板中的 `LP:` 计数

**预期结果:**
- 每次检测到落点时，`LP:` 计数增加
- 控制台输出落点信息: `[Landing #N] ...`
- 状态面板显示最后一个落点坐标

**验收标准:** [ ] 通过 / [ ] 失败

---

### TC-04: 清空缓存 (C键)
**步骤:**
1. 确保已有若干落点记录（LP > 0）
2. 按下 `C` 键

**预期结果:**
- 控制台输出: `[Landing] 已清空 N 个落点记录`
- 状态面板 `LP:` 显示为 0
- 最后落点信息消失

**验收标准:** [ ] 通过 / [ ] 失败

---

### TC-05: 保存落点到CSV (S键)
**步骤:**
1. 按 `R` 开启录制（创建会话）
2. 进行跳跃产生若干落点
3. 按下 `S` 键

**预期结果:**
- 控制台输出: `[Landing] 已保存 N 个落点到 runs/YYYYMMDD_HHMMSS/landing_points.csv`
- CSV 文件包含正确的表头和数据

**验收标准:** [ ] 通过 / [ ] 失败

---

### TC-06: 未开启会话时保存
**步骤:**
1. 启动程序（不按 R）
2. 直接按 `S` 键

**预期结果:**
- 控制台输出: `[保存] 请先按 R 开始录制会话`
- 不创建任何文件

**验收标准:** [ ] 通过 / [ ] 失败

---

### TC-07: 性能统计输出

1. 启动程序

  ```
  [Perf] Inference: XX.X/XX.Xms | Depth: X.X/X.Xms | Landing: X.X/X.Xms
  ```
- 格式: 平均值/最大值

**验收标准:** [ ] 通过 / [ ] 失败
