  🖥️ 迁移到Windows系统

  步骤概览

  1. 复制整个YOLO文件夹到Windows
  2. 安装依赖 (详见 README/DEPLOYMENT_GUIDE.md):
    - Visual Studio 2019+ (C++开发)
    - CMake 3.10+
    - OpenCV (下载预编译包或使用vcpkg)
    - ONNX Runtime (下载Windows版本)
  3. 替换SDK库文件:
  需要从原IMSEE-SDK的 lib/win10-x64/ 获取:
  - indemind.dll
  - indemind.lib

  替换 YOLO/lib/ 中的 libindemind.so
  4. 编译项目:
  # 打开 "Developer Command Prompt for VS 2019"
  cd C:\path\to\YOLO
  build_windows.bat
  5. 运行程序:
  cd build\Release
  yolo_pose_detection.exe

  Windows关键注意事项

  ⚠️ SDK库文件不同:
  - Linux: libindemind.so
  - Windows: indemind.dll + indemind.lib (两个文件)

  ⚠️ 需要手动获取Windows版SDK:
  从原SDK的 IMSEE-SDK/lib/win10-x64/ 复制到 YOLO/lib/

  ⚠️ DLL依赖管理:
  确保以下DLL在PATH或程序目录:
  - indemind.dll (IMSEE)
  - onnxruntime.dll (ONNX Runtime)
  - opencv_world4xx.dll (OpenCV)
