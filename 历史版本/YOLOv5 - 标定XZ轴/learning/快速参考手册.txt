【COCO 17关键点】
  0-鼻子   1-左眼   2-右眼   3-左耳   4-右耳
  5-左肩   6-右肩   7-左肘   8-右肘
  9-左腕  10-右腕  11-左臀  12-右臀
 13-左膝  14-右膝  15-左踝  16-右踝

【模型格式】
  输入: [1, 3, 640, 640]
        ↑  ↑   ↑    ↑
      batch 通道 高  宽

  输出: [1, 56, 8400]
        ↑   ↑     ↑
      batch 属性  候选框

  56个属性:
    [0-3]   bbox (cx, cy, w, h)
    [4]     confidence
    [5-55]  17个关键点 × 3 (x, y, vis)

【置信度阈值】
  0.9  -> 很确定
  0.7  -> 比较确定
  0.5  -> 及格线(默认)
  0.3  -> 不太确定
  <0.3 -> 基本是误检

【检测流程8步】
  1. 相机采集 (640x400 灰度)
  2. 转彩色   (BGR 3通道)
  3. 预处理   (resize→640x640, 归一化)
  4. ONNX推理 (神经网络计算)
  5. 后处理   (解析输出,NMS去重)
  6. 结果输出 (PoseResult数组)
  7. 可视化   (绘制骨架)
  8. 显示     (cv::imshow)

【2D → 3D】(需要深度图和相机内参)
  X = (u - cx) * Z / fx
  Y = (v - cy) * Z / fy
  Z = depth(u, v)

  其中:
    (u,v) = 2D像素坐标
    (X,Y,Z) = 3D相机坐标(毫米)
    fx,fy = 焦距
    cx,cy = 光心

【相机内参矩阵】
  K = [fx  0  cx]
      [0  fy  cy]
      [0   0   1]

【编译错误】
  'vector' is not a member of 'std'
  → 添加: #include <vector>

  undefined reference to `cv::imread'
  → CMakeLists.txt中添加OpenCV链接

【运行错误】
  Segmentation fault
  → 检查指针是否为空,数组是否越界

  Failed to load model
  → 检查.onnx文件路径是否正确

  Cannot open camera
  → 1) 检查相机连接
    2) 使用sudo运行
    3) 检查USB权限

【性能问题】
  FPS太低
  → 1) 使用yolov8n-pose(最快)
    2) 降低图像分辨率
    3) 关闭其他程序
    4) 考虑GPU加速
