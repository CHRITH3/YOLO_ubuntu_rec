1. 什么是神经网络？
================================================================================

类比单片机的逻辑:

[传统编程 (你熟悉的)]
    if (温度 > 30) {
        打开风扇;
    } else {
        关闭风扇;
    }
    规则是人写的!

[神经网络 (机器学习)]
    给计算机看100万张图片:
    - "这是猫"
    - "这是狗"
    - "这是人"

    计算机自己总结规律: "哦，猫有尖耳朵，狗有长鼻子，人直立行走..."
    规则是机器学出来的!

简单理解:
    神经网络 = 一个复杂的数学函数
    输入: 图片 (640x640像素)
    输出: 这是什么? (猫/狗/人...)

2. 什么是"训练"和"推理"？
================================================================================

[训练 Training]
    - 在实验室进行，需要几天到几周
    - 需要大量数据 (几十万张图片)
    - 需要强大GPU
    - 产出: 一个.pt或.onnx模型文件
    - 比喻: 学生在学校学习

[推理 Inference] ⭐ 我们项目做的是这个!
    - 使用训练好的模型
    - 输入一张图片，快速给出结果 (几十毫秒)
    - 不需要重新学习
    - 比喻: 学生毕业后应用知识

你的项目中:
    prepare_yolo_model.py  -> 下载别人训练好的模型
    yolo_pose_detector.cpp -> 加载模型，进行推理

3. 什么是YOLO？
================================================================================

YOLO = You Only Look Once (只看一次)

[传统方法 (慢)]
    1. 先找出图中可能有物体的区域
    2. 对每个区域判断是什么
    3. 需要扫描图片很多次

[YOLO方法 (快)]
    1. 把图片分成7x7=49个格子
    2. 每个格子同时判断: 有没有物体? 是什么? 在哪?
    3. 只看一次图片就完成!

这就是YOLO快的秘密 -> 适合实时应用!

================================================================================
4. YOLOv8-pose 专门做什么？
================================================================================

普通YOLO: 检测物体 (汽车、行人、猫...)
         输出: 边界框 + 类别

YOLOv8-pose: 检测人体姿态
             输出: 边界框 + 17个关键点 (鼻子、眼睛、肩膀...)

关键点编号 (COCO 17格式):
     0: 鼻子           5: 左肩           11: 左臀
     1: 左眼           6: 右肩           12: 右臀
     2: 右眼           7: 左肘           13: 左膝
     3: 左耳           8: 右肘           14: 右膝
     4: 右耳           9: 左腕           15: 左脚踝
                      10: 右腕           16: 右脚踝

应用场景:
    - 健身姿势纠正
    - 体感游戏
    - 安全监控
    - 运动分析

5. 什么是ONNX？
================================================================================

问题: 不同框架的模型格式不兼容
    - PyTorch训练的模型 -> .pt文件
    - TensorFlow训练的模型 -> .pb文件
    - 不能互相使用!

ONNX解决方案:
    - 通用模型格式 (.onnx文件)
    - 任何框架训练的模型都可以转成ONNX
    - 可以在C++、Python、Java等语言中运行

你的项目:
    PyTorch训练 -> .pt文件 -> 转换 -> .onnx文件 -> C++推理

================================================================================
6. 什么是ONNX Runtime？
================================================================================

ONNX Runtime = 运行ONNX模型的"引擎"

类比:
    ONNX模型文件 = MP3音乐文件
    ONNX Runtime = 音乐播放器

你的代码中:
    session_->Run(...)  // 调用ONNX Runtime执行推理

好处:
    - 跨平台 (Windows/Linux/Mac)
    - 优化好，速度快
    - 支持CPU和GPU

7. 模型的输入输出格式
================================================================================

[输入]
    格式: [1, 3, 640, 640]
    解释:
        1    -> batch size (一次处理1张图片)
        3    -> 通道数 (RGB三通道)
        640  -> 高度
        640  -> 宽度

    数据类型: float32
    数值范围: [0, 1] (归一化后)

[输出]
    格式: [1, 56, 8400]
    解释:
        1     -> batch size
        56    -> 每个检测框的信息
                 ├ 0-3: bbox (cx, cy, w, h) 边界框
                 ├ 4: confidence (置信度)
                 └ 5-55: 17个关键点 × 3 (x, y, visibility)
        8400  -> 候选检测框数量

    后处理需要:
        1. 过滤低置信度的检测 (< 0.5)
        2. NMS去除重复检测
        3. 坐标转换到原图尺寸

================================================================================
8. 什么是置信度 (Confidence)？
================================================================================

置信度 = 模型对结果的"确信程度"

范围: 0.0 ~ 1.0
    0.95 -> 95%确定这里有人
    0.50 -> 50%确定(不太确定)
    0.10 -> 10%确定(基本是误检测)

你的代码中:
    conf_threshold_ = 0.5f;  // 只保留 >= 50% 的检测

关键点也有置信度:
    kp.confidence > 0.8  -> 这个关键点检测很准确
    kp.confidence < 0.3  -> 可能检测错了或被遮挡

================================================================================
9. 什么是NMS (非极大值抑制)？
================================================================================

问题: 一个人可能被检测多次

Before NMS:
    [人1] 置信度0.9
    [人1] 置信度0.85  <- 重复!
    [人1] 置信度0.7   <- 重复!
    [人2] 置信度0.8

NMS处理:
    1. 按置信度排序
    2. 保留最高的
    3. 删除与它重叠度 > 45% 的框

After NMS:
    [人1] 置信度0.9   <- 只保留一个
    [人2] 置信度0.8

代码位置: yolo_pose_detector.cpp:273

10. 项目数据流程总结
================================================================================

完整流程:

    相机采集图片 (640x400 灰度)
         ↓
    转RGB (640x400x3)
         ↓
    预处理 Preprocess()
         ├ Letterbox resize -> 640x640
         ├ BGR → RGB
         ├ 归一化 [0, 255] → [0, 1]
         └ HWC → CHW (高宽通道 -> 通道高宽)
         ↓
    ONNX推理 session_->Run()
         ↓
    原始输出 [1, 56, 8400]
         ↓
    后处理 Postprocess()
         ├ 解析56维向量
         ├ 过滤低置信度
         ├ NMS去重
         └ 坐标转换到原图
         ↓
    结果: std::vector<PoseResult>
         ↓
    绘制 DrawPoses()
         ↓
    显示到屏幕
