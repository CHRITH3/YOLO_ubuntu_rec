● 我来详细解释坐标变换的原理和实现过程：

  1. 坐标系的概念

  相机坐标系（原始坐标系）

  - 原点：相机的光心位置
  - 坐标轴：相机固有的X、Y、Z轴
  - 表示：任意3D点 P_cam = [X_cam, Y_cam, Z_cam]^T

  新坐标系（自定义坐标系）

  - 原点：用户点击的P1点
  - X轴：P1→P2方向
  - Z轴：P3→P1方向（即用户要求的"P1到P3的反方向"）
  - Y轴：右手系自动生成（Z × X）

  ---
  2. 坐标变换的数学原理

  核心公式

  P_new = R^T * (P_cam - Origin)

  其中：
  - P_cam：点在相机坐标系中的坐标 [X_cam, Y_cam, Z_cam]^T
  - Origin：新坐标系原点（P1）在相机坐标系中的坐标
  - R：旋转矩阵（3×3）
  - P_new：点在新坐标系中的坐标 [X_new, Y_new, Z_new]^T

  为什么是 R^T 而不是 R？

  这是因为R矩阵表示的是"新坐标系的基向量在相机坐标系中的表示"，而我们需要的
  是"点在新坐标系中的坐标"，所以需要转置（逆变换）。

  4. 坐标变换的实现

  TransformToNewFrame() 函数（get_pose_indemind_left.cpp:231-256）

  cv::Point3d TransformToNewFrame(const cv::Point3d &point_cam) const {
    // Step 1: 平移 - 将原点移到P1
    cv::Point3d relative(point_cam.x - origin_.x,
                         point_cam.y - origin_.y,
                         point_cam.z - origin_.z);

    // Step 2: 旋转 - 使用R^T变换到新坐标系
    cv::Point3d new_coords;

    // new_coords.x = R^T的第一行 · relative
    new_coords.x = R[0,0] * relative.x + R[1,0] * relative.y + R[2,0] *
  relative.z;

    // new_coords.y = R^T的第二行 · relative
    new_coords.y = R[0,1] * relative.x + R[1,1] * relative.y + R[2,1] *
  relative.z;

    // new_coords.z = R^T的第三行 · relative
    new_coords.z = R[0,2] * relative.x + R[1,2] * relative.y + R[2,2] *
  relative.z;

    return new_coords;
  }

  5. 具体例子说明

  假设：
  - P1 (原点): [1000, 500, 2000] mm
  - P2: [1500, 500, 2000] mm → X轴指向正右方
  - P3: [1000, 500, 2500] mm → Z轴指向正后方（P3→P1是向前）
  - 左髋坐标: [1200, 300, 2100] mm

  计算过程：

  Step 1: 计算基向量
  X_vec = (P2 - P1) / ||P2 - P1|| = [500, 0, 0] / 500 = [1, 0, 0]
  Z_vec = (P1 - P3) / ||P1 - P3|| = [0, 0, -500] / 500 = [0, 0, -1]
  Y_vec = Z × X = [0, 0, -1] × [1, 0, 0] = [0, -1, 0]

  Step 2: 旋转矩阵
  R = [1   0   0 ]
      [0  -1   0 ]
      [0   0  -1 ]

  Step 3: 平移
  relative = hip_cam - origin = [1200, 300, 2100] - [1000, 500, 2000]
           = [200, -200, 100]

  Step 4: 旋转（R^T）
  R^T = [1   0   0 ]
        [0  -1   0 ]
        [0   0  -1 ]

  hip_new = R^T * relative = [1   0   0 ] * [200 ]   = [200 ]
                             [0  -1   0 ]   [-200]     [200 ]
                             [0   0  -1 ]   [100 ]     [-100]

  结果：左髋在新坐标系中的坐标是 [200, 200, -100] mm

  ---
  6. 为什么使用 R^T？

  几何解释：

  R矩阵表示：新坐标系的基向量用相机坐标系表示
  - R的第1列 = 新X轴在相机系中的表示
  - R的第2列 = 新Y轴在相机系中的表示
  - R的第3列 = 新Z轴在相机系中的表示

  R^T矩阵表示：相机坐标系的基向量用新坐标系表示（逆变换）

  当我们想知道"一个点在新坐标系中的坐标"时，实际上是在问：
  这个点（相对于新原点）在新坐标系的X、Y、Z三个方向上的分量是多少？

  这就是投影操作，需要使用R^T：
  X_new = X_vec · relative  = R^T的第1行 · relative
  Y_new = Y_vec · relative  = R^T的第2行 · relative
  Z_new = Z_vec · relative  = R^T的第3行 · relative

  总结

  坐标变换的两个关键步骤：
  1. 平移：relative = P_cam - Origin（将原点移到P1）
  2. 旋转：P_new = R^T * relative（将轴对齐到新坐标系）

  旋转矩阵R的含义：
  - R是正交矩阵（R^T = R^-1）
  - R的列向量是新坐标系基向量在旧坐标系中的表示
  - R^T用于将点从旧坐标系变换到新坐标系
