  修改位置: get_pose_indemind_left.cpp:424-489

  功能实现:
  1. 检测条件:
    - 只有在检测到骨架（!poses.empty()）且有深度数据（!depth_data.empty()）
  时才处理
    - 检查第11个关键点的置信度是否 > 0.6
    - 验证关键点坐标在深度图范围内
    - 确保深度值有效（0 < Z < 10000 mm）
  2. 3D坐标计算:
    - 获取第11个关键点（左髋部）的2D像素坐标 (px, py)
    - 从深度图中读取对应的深度值 Z
    - 使用相机内参矩阵 cv_in_left_inv 计算3D坐标：
    [X, Y, Z]^T = K^-1 * Z * [px, py, 1]^T
  3. 可视化显示:
    - 在YOLO Pose窗口上叠加显示文字
    - 格式: Left Hip (KP11): [X, Y, Z] mm
    - 文字位置：在关键点下方30像素处
    - 黑色背景 + 青色文字，便于阅读
    - 自动调整位置防止超出图像边界
  4. 多人支持:
    - 遍历所有检测到的人
    - 为每个满足条件的人显示其左髋部3D坐标
