# 3D坐标检查功能说明

## 功能概述

为 `get_pose_indemind_left.cpp` 程序添加了鼠标点击获取区域3D坐标的功能，参考了 `demo/get_depth_with_region.cpp` 例程的实现。

**设计目标**：简洁实用，只显示必要的信息，不增加额外窗口。

## 新增功能

### 1. 鼠标交互（在YOLO Pose窗口）
- **鼠标移动**：实时预览鼠标位置的深度值
- **左键点击**：锁定选中的区域进行详细检查
- **再次点击选中区域**：解除锁定

### 2. 区域深度详情显示
当鼠标在YOLO Pose窗口上点击时，会弹出 `region` 窗口，显示：
- **7x7 深度值网格**：显示选中点周围的深度值（单位：毫米）
- **中心点标记**：红色高亮显示中心点
- **图像坐标**：`[row, col]` 格式
- **3D相机坐标**：`[X, Y, Z]` 格式（单位：毫米）

## 实现细节

### 核心组件

#### DepthRegion 类
```cpp
class DepthRegion {
public:
  explicit DepthRegion(std::uint32_t n);  // n=3, 表示3x3区域（实际显示7x7）

  // 处理鼠标事件
  void OnMouse(const int &event, const int &x, const int &y, const int &flags);

  // 显示区域深度值网格
  template <typename T>
  void ShowElems(const cv::Mat &depth, ...);

  // 在深度图上绘制选择框
  void DrawRect(cv::Mat &image);
};
```

#### 3D坐标计算
使用相机内参矩阵将2D图像坐标和深度值转换为3D相机坐标：
```
[X]   [fx  0  cx]^-1      [u]
[Y] = [ 0 fy  cy]    * Z * [v]
[Z]   [ 0  0   1]         [1]
```

其中：
- `(u, v)` 是图像坐标
- `Z` 是深度值（毫米）
- `fx, fy, cx, cy` 是相机内参
- `(X, Y, Z)` 是相机坐标系下的3D坐标

### 新增变量

```cpp
// 全局相机内参矩阵
static cv::Mat cv_in_left, cv_in_left_inv;

// 深度数据队列
std::queue<cv::Mat> depth_queue;
std::mutex mutex_depth;

// 深度区域交互对象
DepthRegion depth_region(3);
```

### 深度处理回调

```cpp
if (m_pSDK->EnableDepthProcessor()) {
  m_pSDK->RegistDepthCallback([&](double time, cv::Mat depth) {
    // 将深度从米转换为毫米
    cv::Mat depth_mm;
    depth.convertTo(depth_mm, CV_16U, 1000.0);
    depth_queue.push(depth_mm);
  });
}
```

## 使用方法

### 编译
```bash
cd build
make yolo_pose_indemind_left
```

### 运行
```bash
sudo ./build/yolo_pose_indemind_left
```

### 操作步骤
1. 程序运行后会显示主窗口：
   - `YOLO Pose - INDEMIND Left Camera`：姿态检测结果

2. 在YOLO Pose窗口中：
   - 移动鼠标查看不同位置（无需点击）
   - 点击感兴趣的位置锁定显示
   - 查看 `region` 窗口中的详细深度数据和3D坐标（点击后自动弹出）

3. 键盘控制（与原功能保持一致）：
   - `q` / `ESC`：退出
   - `b`：切换边界框显示
   - `k`：切换关键点显示
   - `s`：切换骨架显示
   - `i`：切换信息叠加层
   - `SPACE`：保存当前帧

## 技术要点

### 1. 线程安全
使用 mutex 保护深度队列，避免多线程访问冲突。

### 2. 队列管理
深度队列限制为最多2帧，避免积压过多数据。

### 3. 坐标系统
- 图像坐标：原点在左上角，单位为像素
- 相机坐标：原点在相机光心，单位为毫米
  - X 轴：向右
  - Y 轴：向下
  - Z 轴：向前（深度方向）

### 4. 深度值范围
- 有效范围：0 - 10000 mm（0 - 10米）
- 超过10米显示为 "invalid"

## 性能影响

添加3D坐标检查功能后的性能变化：
- **CPU 使用率**：略微增加（增加深度处理回调）
- **FPS**：基本无影响（深度处理在独立回调中）
- **内存占用**：增加约 2-3 MB（深度数据缓存）
- **窗口数量**：仅2个窗口，界面简洁

## 注意事项

1. **需要sudo权限**：访问INDEMIND相机需要root权限
2. **深度有效性**：确保场景中有纹理，否则深度值可能无效
3. **光照条件**：良好的光照有助于获得更准确的深度数据
4. **窗口管理**：仅2个窗口，无需多显示器
