# 延迟确认、基于Z值的加权平均和参数实时调整功能

## 更新日期
2024年12月30日

## 功能概述

本次更新对落点（极低点）检测算法进行了重大优化，解决了原始方案中单帧数据噪声大、准确度低的问题，并添加了运行时参数调整功能。

### 主要改进
1. **延迟确认机制**：检测到潜在极低点后等待多帧确认，减少误检测
2. **基于Z值的加权平均**：对极低点附近多帧数据进行加权平均，提高坐标精度
3. **运行时参数调整**：通过键盘快捷键实时调整检测参数

---

## 一、问题背景

### 原始方案的问题

原始方案在检测到极低点瞬间直接取单帧的X、Y坐标：

```cpp
// 原始方案：直接使用当前帧坐标
lp.new_frame_x = hip.new_frame_pos.x;
lp.new_frame_y = hip.new_frame_pos.y;
```

**存在的问题**：
1. 单帧数据受深度传感器噪声影响大
2. 髋部关键点检测本身存在抖动
3. 极低点瞬间的坐标可能不是最稳定的采样点
4. 容易因噪声产生误检测

---

## 二、延迟确认机制

### 设计思路

不在检测到极低点时立即记录，而是等待后续帧确认确实是极低点：

```
时间轴：
    ───●───●───●───★───●───●───●───●───●───
                    ↑           ↑
                 检测到        确认
                潜在极低点    （5帧后）
```

### CheckLandingPoint 方法重写 (第565-645行)

```cpp
void CheckLandingPoint(const HipInfo &hip) {
  double current_z = hip.new_frame_pos.z;
  auto now = std::chrono::steady_clock::now();

  // 1. 将当前帧数据加入缓冲区
  FrameData fd;
  fd.x = hip.new_frame_pos.x;
  fd.y = hip.new_frame_pos.y;
  fd.z = hip.new_frame_pos.z;
  fd.timestamp = now;
  frame_buffer_.push_back(fd);

  // 2. 维护缓冲区大小
  while (frame_buffer_.size() > BUFFER_SIZE) {
    frame_buffer_.pop_front();
    // 调整待确认极低点的索引
    if (has_pending_minimum_ && pending_min_index_ > 0) {
      pending_min_index_--;
    } else if (has_pending_minimum_ && pending_min_index_ <= 0) {
      // 缓冲区溢出导致丢失待确认极低点
      has_pending_minimum_ = false;
      pending_min_index_ = -1;
      frames_since_minimum_ = 0;
    }
  }

  // 3. 使用可调整的噪声阈值
  double noise_threshold = noise_threshold_;

  // 4. 延迟确认逻辑
  if (has_pending_minimum_) {
    frames_since_minimum_++;
    double min_z = frame_buffer_[pending_min_index_].z;
    bool still_ascending = (current_z > min_z + noise_threshold * 0.5);

    if (still_ascending && frames_since_minimum_ >= CONFIRM_FRAMES) {
      // 确认成功！计算加权平均并记录落点
      ConfirmLandingPoint();
      // 重置状态
      has_pending_minimum_ = false;
      pending_min_index_ = -1;
      frames_since_minimum_ = 0;
      was_descending_ = false;
    } else if (!still_ascending && current_z < min_z) {
      // 发现更低的点，更新待确认极低点
      pending_min_index_ = frame_buffer_.size() - 1;
      frames_since_minimum_ = 0;
    } else if (frames_since_minimum_ > BUFFER_SIZE) {
      // 超时，取消待确认极低点
      has_pending_minimum_ = false;
      pending_min_index_ = -1;
      frames_since_minimum_ = 0;
    }
  } else {
    // 5. 检测新的潜在极低点
    bool significant_descent = (last_new_z_ - current_z) > noise_threshold;
    bool is_ascending = (current_z > last_new_z_);

    if (was_descending_ && is_ascending &&
        (current_z - last_new_z_) > noise_threshold * 0.5) {
      // 检测到潜在极低点（前一帧）
      has_pending_minimum_ = true;
      pending_min_index_ = frame_buffer_.size() - 2;
      frames_since_minimum_ = 1;
    }

    if (significant_descent) {
      was_descending_ = true;
    }
  }

  last_new_z_ = current_z;
}
```

## 三、基于Z值的加权平均

### 设计思路

落地瞬间（Z值最低）的位置最能代表真实落点位置。通过加权平均，让Z值更接近极低点的帧对最终坐标贡献更大。

```
时间轴：
    ───●───●───●───★───●───●───●───
       -3  -2  -1   0  +1  +2  +3  (相对帧)
                    ↑
                 极低点

权重分配：
    w_i = 1 / (|Z_i - Z_min| + ε)

    Z越接近极低点 → |Z_i - Z_min| 越小 → 权重越大
```

### ConfirmLandingPoint 方法 (第652-724行)

```cpp
void ConfirmLandingPoint() {
  if (pending_min_index_ < 0 ||
      pending_min_index_ >= static_cast<int>(frame_buffer_.size())) {
    return;
  }

  // 1. 在缓冲区附近搜索真正的最小Z值
  double min_z = frame_buffer_[pending_min_index_].z;
  int actual_min_idx = pending_min_index_;

  int search_start = std::max(0, pending_min_index_ - 3);
  int search_end = std::min(static_cast<int>(frame_buffer_.size()) - 1,
                            pending_min_index_ + 3);

  for (int i = search_start; i <= search_end; i++) {
    if (frame_buffer_[i].z < min_z) {
      min_z = frame_buffer_[i].z;
      actual_min_idx = i;
    }
  }

  // 2. 定义加权平均窗口（使用可调整的窗口半径）
  int window_start = std::max(0, actual_min_idx - window_half_);
  int window_end = std::min(static_cast<int>(frame_buffer_.size()) - 1,
                            actual_min_idx + window_half_);

  // 3. 计算加权平均
  constexpr double epsilon = 1.0;  // 防止除零
  double weight_sum = 0.0;
  double weighted_x = 0.0;
  double weighted_y = 0.0;

  for (int i = window_start; i <= window_end; i++) {
    double z_diff = std::abs(frame_buffer_[i].z - min_z);
    double weight = 1.0 / (z_diff + epsilon);

    weighted_x += weight * frame_buffer_[i].x;
    weighted_y += weight * frame_buffer_[i].y;
    weight_sum += weight;
  }

  // 4. 计算最终坐标
  double final_x = weighted_x / weight_sum;
  double final_y = weighted_y / weight_sum;

  // 5. 计算时间并记录落点
  auto min_timestamp = frame_buffer_[actual_min_idx].timestamp;
  auto elapsed_ms = std::chrono::duration_cast<std::chrono::milliseconds>(
      min_timestamp - start_time_).count();
  int total_seconds = static_cast<int>(elapsed_ms / 1000);
  int minutes = total_seconds / 60;
  int seconds = total_seconds % 60;

  // 6. 创建落点记录
  landing_count_++;
  LandingPoint lp;
  lp.landing_id = landing_count_;
  lp.time_minutes = minutes;
  lp.time_seconds = seconds;
  lp.new_frame_x = final_x;
  lp.new_frame_y = final_y;
  lp.new_frame_z = min_z;

  landing_points_.push_back(lp);

  // 7. 控制台输出
  std::cout << "\n========================================" << std::endl;
  std::cout << "落点" << lp.landing_id << " (加权平均)：" << std::endl;
  std::cout << "  时间: " << lp.time_minutes << "分" << lp.time_seconds << "秒" << std::endl;
  std::cout << "  新坐标系 X: " << lp.new_frame_x << " mm" << std::endl;
  std::cout << "  新坐标系 Y: " << lp.new_frame_y << " mm" << std::endl;
  std::cout << "  新坐标系 Z (极低点): " << lp.new_frame_z << " mm" << std::endl;
  std::cout << "  采样窗口: " << (window_end - window_start + 1) << " 帧" << std::endl;
  std::cout << "========================================\n" << std::endl;
}
```

### 加权平均示例

假设极低点附近7帧的数据：

| 帧 | Z值 (mm) | |Z - Z_min| | 权重 w | X值 | Y值 |
|----|----------|------------|--------|-----|-----|
| -3 | -40 | 15 | 0.0625 | 120 | 550 |
| -2 | -48 | 7 | 0.125 | 122 | 548 |
| -1 | -53 | 2 | 0.333 | 124 | 545 |
| **0** | **-55** | **0** | **1.0** | **125** | **543** |
| +1 | -52 | 3 | 0.25 | 126 | 544 |
| +2 | -46 | 9 | 0.1 | 128 | 546 |
| +3 | -38 | 17 | 0.056 | 130 | 549 |

```
权重和 = 0.0625 + 0.125 + 0.333 + 1.0 + 0.25 + 0.1 + 0.056 = 1.9265

X_final = (0.0625×120 + 0.125×122 + 0.333×124 + 1.0×125 +
           0.25×126 + 0.1×128 + 0.056×130) / 1.9265
        ≈ 124.7 mm

Y_final = (0.0625×550 + 0.125×548 + 0.333×545 + 1.0×543 +
           0.25×544 + 0.1×546 + 0.056×549) / 1.9265
        ≈ 544.1 mm
```

可以看到，最终坐标更接近极低点帧（帧0）的坐标值。

  std::cout << "[参数调整] Z阈值: " << noise_threshold_ << " mm" << std::endl;

void DecreaseNoiseThreshold(double delta = 10.0) {

// 增加窗口半径 (+1帧)
void IncreaseWindowHalf(int delta = 1) {
  window_half_ += delta;
  if (window_half_ > 7) window_half_ = 7;

## 八、使用建议

### Z阈值调整

- **增大阈值**（如200-300mm）：减少误检测，只检测大幅度的跳跃落地
- **减小阈值**（如50-100mm）：增加灵敏度，检测小幅度的动作

### 窗口半径调整

- **增大半径**（如5-7帧）：更强的平滑效果，适合噪声较大的环境
- **减小半径**（如1-2帧）：更快的响应，保留更多细节

### 典型场景配置

| 场景 | Z阈值 | 窗口半径 |
|------|-------|----------|
| 跳远测试 | 200 mm | 3 帧 |
| 步态分析 | 80 mm | 4 帧 |
| 高噪声环境 | 150 mm | 5 帧 |
| 精确测量 | 100 mm | 2 帧 |
