# 深度测距功能问答（Q&A）

## 问题1：n=3 在哪里设置？

**答案**：在 `get_pose_indemind_left.cpp:232` 行通过构造函数传入：

```cpp
DepthRegion depth_region(3);
```

这里传入参数 `3` 初始化了 `DepthRegion` 对象。在构造函数中（line 38-39），这个值被保存到成员变量 `n_`：

```cpp
explicit DepthRegion(std::uint32_t n)
    : n_(std::move(n)), show_(false), selected_(false), point_(0, 0) {}
```

### 如何修改区域大小

你可以修改这个值来改变测距区域的大小：

- `DepthRegion depth_region(3);` → 矩形框 6×6 像素，网格 7×7 点
- `DepthRegion depth_region(5);` → 矩形框 10×10 像素，网格 11×11 点
- `DepthRegion depth_region(10);` → 矩形框 20×20 像素，网格 21×21 点

## 问题2：矩形框大小是 6×6，为什么 region 窗口显示 7×7 的网格？

**答案**：因为矩形框表示的是**边界范围**，而网格显示的是**采样点个数**。

### 矩形框的大小（DrawRect）

在 `get_pose_indemind_left.cpp:150-152`：

```cpp
cv::rectangle(image, cv::Point(point_.x - n_, point_.y - n_),
              cv::Point(point_.x + n_, point_.y + n_), ...);
```

- 从 `point_.x - n_` 到 `point_.x + n_`（即 `x-3` 到 `x+3`）
- 宽度 = `(x+3) - (x-3) = 6` 像素
- 高度同理也是 6 像素
- **矩形框是 6×6 像素的区域**

### 网格的大小（ShowElems）

在 `get_pose_indemind_left.cpp:102-106`：

```cpp
for (int i = -n_; i <= n_; ++i) {  // i 从 -3 到 +3
    x = point_.x + i;
    for (int j = -n_; j <= n_; ++j) {  // j 从 -3 到 +3
        y = point_.y + j;
        // 采样深度值
    }
}
```

- `i` 取值：`-3, -2, -1, 0, 1, 2, 3`（共 7 个值）
- `j` 取值：`-3, -2, -1, 0, 1, 2, 3`（共 7 个值）
- **网格是 7×7 个采样点**

### 为什么不一样？

**矩形框**表示的是一个**连续的区域**（从 `-n_` 到 `+n_`，范围是 `2n_`）：

```
区域范围：[x-3] 到 [x+3]
长度：6 像素
```

**网格**表示的是**离散的采样点**（从 `-n_` 到 `+n_`，包含两端，共 `2n_+1` 个点）：

```
采样点：[x-3], [x-2], [x-1], [x], [x+1], [x+2], [x+3]
数量：7 个点
```

### 类比说明

想象一把尺子：

- **矩形框**：从 0cm 到 6cm，**长度是 6cm**
- **网格点**：在 0cm, 1cm, 2cm, 3cm, 4cm, 5cm, 6cm 处做标记，**共 7 个标记**

### 计算公式总结

对于参数 `n_`：

| 项目 | 计算公式 | n_=3 的结果 |
|------|---------|------------|
| 矩形框尺寸 | `2 × n_` | 6×6 像素 |
| 网格点数量 | `(2 × n_ + 1) × (2 × n_ + 1)` | 7×7 点 |

## 问题3：`depth pos(3)` 和 `camera pos` 分别显示的是什么信息？

在 `get_pose_indemind_left.cpp:236-238` 的输出格式：

```cpp
os << "depth pos(" << n << "): [" << point.y << ", " << point.x << "]"
   << " camera pos: [" << X << ", " << Y << ", " << Z << "]"
   << ", unit: mm";
```

### `depth pos(3): [y, x]` - 2D 图像坐标

**含义**：鼠标点击位置在**深度图图像**中的**像素坐标**

- **`(3)`**：表示采样半径 `n_=3`（即以此点为中心显示 7×7 的网格）
- **`[y, x]`**：图像坐标（注意是 y 在前，x 在后）
  - `y`：图像的**行号**（从上到下，0 到 height-1）
  - `x`：图像的**列号**（从左到右，0 到 width-1）
- **坐标系**：2D 图像坐标系（像素坐标）
- **单位**：像素（pixel）

**举例**：
```
depth pos(3): [200, 320]
```
表示鼠标点击在图像的第 200 行、第 320 列，以该点为中心显示 7×7 网格。

### `camera pos: [X, Y, Z]` - 3D 空间坐标

**含义**：鼠标点击位置对应的**3D 空间坐标**，在**左相机坐标系**中的真实物理位置

- **坐标系**：左相机坐标系（以相机光心为原点）
  - **X 轴**：指向相机的**右侧**（水平向右）
  - **Y 轴**：指向相机的**下方**（垂直向下）
  - **Z 轴**：指向相机的**前方**（光轴方向，垂直于镜头向外）
- **单位**：毫米（mm）

**举例**：
```
camera pos: [150, -80, 1200]
```
表示该点相对于左相机的位置：
- 向右 **150mm**（X = 150）
- 向上 **80mm**（Y = -80，负值表示在 Y 轴负方向，即向上）
- 前方 **1200mm = 1.2米**（Z = 1200）

### 3D 坐标计算方法

在 `get_pose_indemind_left.cpp:95-100`：

```cpp
// 1. 构建图像坐标的齐次坐标 [u, v, 1]^T
mouse_img_cor.at<double>(0, 0) = point_.x;  // u (列)
mouse_img_cor.at<double>(0, 1) = point_.y;  // v (行)
mouse_img_cor.at<double>(0, 2) = 1.0;

// 2. 获取该点的深度值 Z
double Z = depth.at<T>(point_.y, point_.x);

// 3. 使用针孔相机模型的逆变换
// 公式：[X, Y, Z]^T = K^-1 * Z * [u, v, 1]^T
mouse_left_cor = cv_in_left_inv * Z * mouse_img_cor;
```

其中相机内参矩阵 K 及其逆矩阵：

```
K = [fx   0  cx]       K^-1 = [1/fx    0    -cx/fx]
    [ 0  fy  cy]              [  0   1/fy  -cy/fy]
    [ 0   0   1]              [  0     0       1  ]
```

参数说明：
- `fx`, `fy`：焦距（像素单位）
- `cx`, `cy`：主点（图像中心，像素单位）

### 坐标系可视化

```
        Y (向下)
        |
        |
        |_______ X (向右)
       /
      /
     Z (向前，朝向场景)
```

### 两种坐标对比

| 项目 | depth pos | camera pos |
|------|-----------|------------|
| **类型** | 2D 图像坐标 | 3D 空间坐标 |
| **维度** | 2D (y, x) | 3D (X, Y, Z) |
| **单位** | 像素（pixel） | 毫米（mm） |
| **坐标系** | 图像坐标系 | 相机坐标系 |
| **范围** | 0 ≤ x < 640, 0 ≤ y < 400 | 实际物理范围（毫米） |
| **用途** | 定位图像中的像素 | 描述真实空间中的物理位置 |
| **举例** | `[200, 320]` | `[150, -80, 1200]` |

### 完整输出示例

```
depth pos(3): [200, 320] camera pos: [150.5, -80.2, 1205.8], unit: mm
```

**解读**：
- 点击了图像的第 200 行、第 320 列
- 该点在真实空间中的位置：相机右侧 150.5mm，上方 80.2mm，前方 1205.8mm（约 1.2 米远）
- 显示以此点为中心的 7×7 深度网格（半径为 3）
