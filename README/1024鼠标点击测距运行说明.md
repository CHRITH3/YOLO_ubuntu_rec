# 快速使用指南 - 3D坐标检查功能

## 功能简介

在YOLO姿态检测窗口中，鼠标点击任意位置即可查看该点的3D坐标信息。

## 使用步骤

### 1. 编译程序
```bash
cd /home/chris/Desktop/YOLO/build
make yolo_pose_indemind_left
```

### 2. 运行程序
```bash
sudo ./yolo_pose_indemind_left
```

### 3. 操作说明

**显示窗口**：
- `YOLO Pose - INDEMIND Left Camera`：主窗口，显示姿态检测结果
- `region`：详情窗口，点击后显示3D坐标（自动弹出）

**鼠标操作**：
- 在YOLO Pose窗口中移动鼠标 → 实时预览深度
- 点击感兴趣的位置 → 弹出region窗口显示详细信息
- 再次点击选中区域 → 解除锁定

**键盘控制**：
- `q` 或 `ESC`：退出程序
- `b`：切换边界框
- `k`：切换关键点
- `s`：切换骨架
- `i`：切换信息显示
- `SPACE`：保存当前帧

## region窗口说明

点击YOLO窗口后，region窗口会显示：

```
depth pos(3): [200, 320] camera pos: [45.2, -23.1, 1250.5], unit: mm

  invalid  invalid   823     821     819    invalid  invalid
  invalid   825      824     822     820     818     invalid
   827      826      825     823     821     819      817
   828      827      826    >824<    822     820      818
   829      828      827     825     823     821      819
  invalid   830      829     827     825     823     invalid
  invalid  invalid   831     829     827    invalid  invalid
```

**信息说明**：
- `depth pos(3): [200, 320]` - 图像坐标（行，列）
- `camera pos: [45.2, -23.1, 1250.5]` - 3D相机坐标 X, Y, Z（单位：毫米）
- 数字网格 - 周围7x7区域的深度值
- `>824<` 红色显示 - 中心点深度值
- `invalid` - 无效深度值（超过10米或无纹理）

## 坐标系统

**3D相机坐标系**：
- **X轴**：向右为正
- **Y轴**：向下为正
- **Z轴**：向前为正（深度方向）

**单位**：所有坐标和深度值单位均为毫米（mm）

## 使用场景

1. **测量距离**：点击物体获取距离相机的精确距离（Z坐标）
2. **空间定位**：获取场景中任意点的3D空间坐标
3. **深度验证**：检查深度传感器在不同位置的准确性
4. **关键点测距**：点击人体关键点附近查看深度信息

## 注意事项

- ✅ 需要sudo权限运行（相机访问）
- ✅ 确保场景有足够纹理（光滑表面可能无深度值）
- ✅ 良好光照条件有助于提高深度精度
- ✅ 有效深度范围：0-10米
