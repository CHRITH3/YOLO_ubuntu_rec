# 20260204人体坐标系

本文面向初学者，解释当前人体坐标系（body frame）如何从 3D 关键点构建，以及为何用“躯干对齐的 3D 盒子”替代 YOLO 2D 目标框，并给出具体代码改动位置。

**目标**

在 `get_pose_indemind_left.cpp` 中，停用 YOLO 的 2D 边框显示，改为绘制一个跟随人体姿态旋转的躯干 3D 长方体；同时让人体坐标系轴更细、更长，便于观察方向。

**实现思路**

1. **人体坐标系构建**

坐标系由髋部与肩部关键点构建：

- `y_body` 方向：髋部中点指向肩部中点。
- `x_body` 方向：右髋指向左髋（若髋不可用则用双肩）。
- `z_body` 方向：`x_body × y_body`。

该过程由 `BuildBodyFrameFromPose(...)` 完成，并输出 `R_body_cam`（人体坐标系在相机坐标下的方向矩阵）。

2. **躯干 3D 盒子**

躯干盒子使用人体坐标系旋转。中心点以髋部中点为基准，沿人体 `y` 轴方向上移半个躯干高度。尺寸采用以下规则：高度为肩部中点到髋部中点的距离，宽度为左右肩宽与左右髋宽的平均值，厚度默认取 `宽度 × 0.4` 并设置最小值避免过薄。

如果关键点不完整，则回退到默认尺寸（高度 400mm、宽度 300mm、厚度 120mm）。

3. **投影与绘制**

将人体坐标系中的 8 个立方体角点通过 `R_body_cam` 旋转到相机坐标系，再投影到 2D 图像中，用 12 条边线连成盒子。

**具体代码改动**

文件：`get_pose_indemind_left.cpp`

1. **新增躯干盒子绘制函数**

新增 `DrawBodyFrameBox(...)`：

- 构造 8 个立方体角点（人体坐标系）。
- 通过 `R_body_cam` 旋转到相机坐标系。
- 使用 `ProjectPoint(...)` 投影为 2D 点并连线绘制。

2. **禁用 YOLO 2D 边框显示**

- `show_bbox` 改为 `false`，并移除 `b` 键开关。
- `DrawPoses(...)` 继续调用，但 `show_bbox` 永远为 false。
- 控制台说明和使用说明中移除 “Bounding box”。

3. **绘制躯干盒子（随人体旋转）**

在绘制人体坐标轴的逻辑中：

- 从肩/髋关键点估计躯干高度和宽度。
- 通过 `R_body_cam` 列向量获取人体 `y` 轴方向。
- 计算盒子中心点并调用 `DrawBodyFrameBox(...)`。

4. **人体坐标轴更细更长**

- 轴长度从 200mm 改为 260mm。
- 线宽从 2 改为 1。

**可调参数位置**

在 `get_pose_indemind_left.cpp` 的“绘制 body axes”代码块内：

- `axis_length` 和 `axis_thickness` 控制坐标轴外观。
- `torso_height`、`torso_width`、`torso_depth` 控制盒子尺寸。

**快速验证方法**

运行程序后观察：

- 图像中不再出现 YOLO 绿色 2D 边框。
- 体前方出现一个随人体旋转的 3D 躯干盒子。
- XYZ 坐标轴更细、更长。
