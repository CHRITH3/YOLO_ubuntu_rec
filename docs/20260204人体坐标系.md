# 20260204人体坐标系

本文面向初学者，解释当前人体坐标系（body frame）如何从 3D 关键点构建，以及为何用“躯干对齐的 3D 盒子”替代 YOLO 2D 目标框。以下内容全部对应现有代码实现，不需要改动代码。

**范围与入口**

核心实现集中在 `get_pose_indemind_left.cpp`。3D 关键点的数据结构来自 `yolo_pose_detector.h` 的 `KeyPoint` 与 `PoseResult`，每个关键点都有 `pos3d` 字段用于保存 3D 坐标。

**功能 1：3D 关键点深度管线（从 2D 像素到 3D 坐标）**

深度数据在 `RegistDepthCallback` 中进入系统，回调里把深度从米转换为毫米并压入 `depth_queue`。主循环从队列取出最新深度帧 `depth_data` 后，按下面流程给每个关键点生成 3D 坐标。

1. 在 `pose_detector.Detect(left_image)` 得到 `poses` 后，遍历每个人、每个关键点，只处理置信度大于 0.3 的点。
2. 用关键点的像素位置 `px, py` 访问深度图，如果越界或深度无效则跳过。
3. 通过 `RobustDepthMedianU16(depth_data, px, py, /*r=*/3, z_mm)` 得到该像素周围的稳健深度值 `z_mm`，减少噪声。
4. 用左目内参逆矩阵 `cv_in_left_inv` 做反投影，把像素坐标变成相机坐标系下的 3D 点 `cam_pt`，单位是毫米。
5. 将 3D 点存入 `Pose3DInfo::kp_cam` 并标记 `kp_valid`。如果床面坐标系已经拟合完成，则用 `depth_region.TransformToNewFrame(cam_pt)` 得到床面坐标系下的 3D 点，存入 `Pose3DInfo::kp_bed`。
6. 同步把床面坐标写回 `poses[p].keypoints[k].pos3d`，方便其它绘制或统计复用。

这套流程完全在 `get_pose_indemind_left.cpp` 中完成，因此即使不调用 `pose_utils.cpp` 的 `MapPoseTo3D` 也能获得 3D 关键点。

**功能 2：人体坐标系轴的构建（Body Frame Axes）**

人体坐标系在 `BuildBodyFrameFromPose(...)` 中构建，使用床面坐标系下的髋部和肩部关键点。

1. `y_body` 方向：髋部中点指向肩部中点，代表人体的“向上”方向。
2. `x_body` 方向：右髋指向左髋，如果髋不可用则用右肩指向左肩，代表人体的左右方向。
3. `z_body` 方向：`x_body × y_body`，形成右手系的前后方向。

轴的原点使用髋部中点 `pelvis`。构建完成后把三根单位轴写入 `BodyFrame::R_body_bed` 的三列，然后通过 `R_body_cam = R_bed_cam * R_body_bed` 得到相机坐标系下的人体坐标系方向矩阵。

**功能 3：Gram-Schmidt、R_rel 与四元数**

由于 `x_body` 与 `y_body` 可能不完全垂直，代码用 Gram-Schmidt 正交化保证坐标系是正交单位基。具体做法是先把 `y_raw` 在 `x_axis` 上的投影减掉，得到 `y_orth`，再归一化成 `y_axis`。然后用叉乘得到 `z_axis` 并归一化。

`R_rel` 表示“人体坐标系相对床面坐标系的旋转”，由 `R_rel = R_bed_cam.t() * R_body_cam` 得到。接着用 `RotationMatrixToQuaternion` 生成四元数 `quat`，用 `RotationMatrixToEulerXYZ` 生成欧拉角 `euler_rad`。这两种表示方式在后续的指标窗口中展示。

**功能 4：旋转指标与累计圈数（Rotation Metrics）**

旋转累计由 `RotationTracker` 维护。它保存上一帧欧拉角 `last_angles`，并在 `Update(...)` 中对每一轴的角度差做“跨越 ±π 的展开”，避免从 179 度跳到 -179 度造成突变。

累计角度存入 `RotationTracker::cumulative`。展示时把它换算成度数，并用 `counts = cumulative / (2π)` 转成“圈数”概念，对应界面上的 `Counts (flip/twist/side)`。当人体坐标系连续丢失 3 帧后会调用 `rotation_tracker.Reset()`，防止累计误差被错误地延续。

**功能 5：坐标轴的可视化（Axis Visualization）**

人体坐标轴在“Draw body axes”代码块中绘制。起点是跟踪到的 `pelvis_cam`，终点由 `axis_length` 乘以 `R_body_cam` 的列向量得到。每个 3D 端点都通过 `ProjectPoint(...)` 投影到 2D 画面，再用 `cv::arrowedLine` 画箭头。

颜色与文字标签固定为：X 轴红色标记 `Xb`，Y 轴绿色标记 `Yb`，Z 轴蓝色标记 `Zb`。当前设定的轴长度为 260mm，线宽为 1，便于观察方向变化。

**功能 6：指标窗口（Body Frame Metrics Window）**

指标窗口在每帧生成 `metrics_panel(950x650)` 并通过 `cv::imshow("Body Frame Metrics", metrics_panel)` 显示。它包含以下几类信息。

1. 床面坐标系状态 `Trampoline frame: READY/NOT READY`，用来提示是否完成 ROI 拟合。
2. 当前跟踪的人 `Tracked person`，与 `tracked_pose_index` 对应。
3. 如果人体坐标系有效，会显示四元数、欧拉角（度）、累计角度（度）和累计圈数。
4. 下半部分是 `3D Skeleton (trampoline coords, mm)`，逐行列出每个关键点在床面坐标系下的 3D 坐标，若无数据则显示 `N/A`。

窗口不依赖其他线程或异步机制，完全由主循环实时刷新。

**躯干 3D 盒子与 2D 框替换（背景说明）**

为了让用户更直观地看到身体朝向，程序在 `DrawBodyFrameBox(...)` 中绘制一个跟随人体姿态旋转的 3D 躯干盒子，并将 YOLO 2D 边框关闭（`show_bbox = false`）。盒子中心以髋部中点为基准，沿 `y_body` 方向上移半个躯干高度。尺寸规则如下。

1. 高度为肩部中点到髋部中点的距离。
2. 宽度为左右肩宽与左右髋宽的平均值。
3. 厚度为 `宽度 × 0.4`，且设置最小值避免过薄。

当关键点不完整时回退到默认尺寸，分别是高度 400mm、宽度 300mm、厚度 120mm。盒子的 8 个角点先在人体坐标系中定义，再用 `R_body_cam` 旋转到相机坐标系，最后用 `ProjectPoint(...)` 投影成 2D 线框。
