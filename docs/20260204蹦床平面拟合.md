# 2026-02-04 蹦床平面拟合（4 点 ROI + RANSAC）实现说明

本文面向 C++ 初学者，解释本仓库中“4 点 ROI 选择 + RANSAC 蹦床平面拟合”的实现流程、关键类/函数与坐标系构建方法，并对照实际代码文件说明改动。

## 1. 功能概述（做了什么）
- 从“3 次点击”改为“4 点 ROI（矩形/四边形）”：在图像上点 4 个蹦床床面角点。第 5 次点击会清空并重新开始。
- 在 ROI 内采样深度点，用 **RANSAC** 拟合平面，再用 **内点** 做一次最小二乘精修。
- 由平面构建“蹦床坐标系”：
  - **Z 轴**：平面法向量（指向“上方”）。
  - **X 轴**：ROI 最长边方向，并且指向图像右侧（x 方向增加）。
  - **Y 轴**：`Y = Z × X`，保证右手系。

涉及文件（和本次改动直接相关）：
- `app/depth_region.h`：ROI 选择、平面拟合、坐标系构建与坐标转换。
- `get_pose_indemind_left.cpp`：UI 提示文字、鼠标回调与“Trampoline Frame: READY”的状态显示。

## 2. 用户操作流程（运行时怎么用）
1. 运行 `./build/yolo_pose_indemind_left` 打开窗口 `YOLO Pose - INDEMIND Left Camera`。
2. 在图像上 **依次点击 4 个蹦床床面角点**（顺时针或逆时针均可）。
3. 第 4 次点击后会自动拟合平面，并在 `region` 窗口里看到：
   - ROI 点列表
   - Plane inliers 数量与比例
   - `Trampoline Frame: READY`
4. 如果还想重新选择 ROI，**再点击一次**即可清空并重新开始。

对应代码位置：
- `get_pose_indemind_left.cpp` 内打印了交互说明与注册鼠标回调（`cv::setMouseCallback`）。
- `app/depth_region.h` 的 `DepthRegion::OnMouse` 记录点击并触发拟合。

## 3. 关键类与函数（从代码入口到算法核心）
### 3.1 `DepthRegion` 类（`app/depth_region.h`）
主要负责 ROI 选择、平面拟合、坐标系建立、以及坐标转换：
- `OnMouse(...)`
  - 记录 4 次点击的 ROI 角点。
  - 当点击数达到 4 时，设置 `pending_roi_finalize_ = true`。
  - 如果已有 4 点，再点击会先调用 `ResetRoiSelection()` 重新开始。
- `ShowElems(...)`
  - 每帧显示鼠标位置与坐标信息。
  - 如果检测到 `pending_roi_finalize_`，调用 `TryFinalizePlaneFromROI(depth)`。
- `TryFinalizePlaneFromROI(const cv::Mat& depth)`
  - ROI → 深度采样 → RANSAC → 精修 → 建立坐标系。
- `FitPlaneRansac(...)`
  - 随机采样 3 点估计平面，统计内点数，取内点最多的平面。
- `FitPlaneLeastSquares(...)`
  - 用内点集做协方差矩阵特征分解，得到更稳定的法向量。
- `BuildFrameFromPlane(...)`
  - 从平面和 ROI 最长边定义 X/Y/Z，构建旋转矩阵与坐标系原点。
- `TransformToNewFrame(...)`
  - 把相机坐标系下的点转换为“蹦床坐标系”坐标。

## 4. 算法步骤（和代码一一对应）
下面流程可直接对应到 `TryFinalizePlaneFromROI`：

1. **ROI 点规范化**
   - 使用 `cv::convexHull` 重新排序 4 点，保证是凸四边形。

2. **ROI 内采样深度点**
   - 根据 ROI 生成 mask。
   - 以 `roi_sample_step_ = 4` 的步长遍历像素。
   - 过滤深度为 0 或过大（`>= 10000`）的无效点。
   - 像素点 `(x, y)` + 深度 `z_mm` 转为相机坐标：
     - `pt_cam = cv_in_left_inv * z_mm * [x, y, 1]^T`

3. **RANSAC 平面拟合**（`FitPlaneRansac`）
   - 迭代次数：`ransac_max_iters_ = 200`
   - 内点阈值：`ransac_inlier_thresh_mm_ = 15.0`
   - 从样本中随机取 3 点估平面，统计所有点到平面的距离，距离小于阈值的是内点。

4. **内点精修**（`FitPlaneLeastSquares`）
   - 对所有内点求均值与协方差矩阵。
   - 取最小特征值对应的特征向量作为法向量。
   - 得到更稳定的平面参数 `n·p + d = 0`。

5. **构建坐标系**（`BuildFrameFromPlane`）
   - **Z 轴**：平面法向量 `n`。
   - 若相机坐标系 `Y+` 表示“向下”，代码会把 `Z` 翻转成“向上”。
   - 选取 ROI **最长边**作为 X 轴参考方向，并保证 X 指向图像右侧。
   - `Y = Z × X`，再用 `X = Y × Z` 做一次正交化，保证右手系。
   - 坐标系原点 `origin_` 为内点均值。
   - 旋转矩阵 `rotation_matrix_` 的三列分别是 X/Y/Z 轴在相机坐标系下的方向。

## 5. 坐标系定义（重点）
- **Z 轴**：平面法向量，指向“上”。
- **X 轴**：ROI 最长边方向，且在图像上指向右侧（`x` 增加方向）。
- **Y 轴**：`Y = Z × X`。
- **原点**：平面内点的均值（中心位置）。
- **坐标变换**：`TransformToNewFrame` 使用 `R^T * (P - origin)` 把相机坐标转到蹦床坐标。

## 6. 关键参数与限制
- `roi_sample_step_ = 4`：采样步长，越小越密但更慢。
- `ransac_max_iters_ = 200`：RANSAC 迭代次数。
- `ransac_inlier_thresh_mm_ = 15.0`：内点距离阈值（毫米）。
- 若 ROI 深度样本太少（少于 50），会提示不足并放弃拟合。

## 8. 数学基础速览（给 C++ 初学者）
这一节只讲“够用”的直觉，方便你读代码时不迷路。

**8.1 平面方程（ax + by + cz + d = 0）**
- 一个平面可以写成 `a*x + b*y + c*z + d = 0`。
- 向量 `n = (a, b, c)` 是平面的法向量，垂直于平面。
- 任意点 `p = (x, y, z)` 到平面的“符号距离”与 `n·p + d` 成正比；代码里用它判断内点。

**8.2 RANSAC 的想法（先粗拟合，抗异常）**
- 数据里有噪声和离群点时，直接最小二乘会被“带偏”。
- RANSAC 做法：随机取 3 个点先估平面 → 统计有多少点“接近”该平面 → 保留内点最多的那个。
- 这样能先找到一个“靠谱的大致平面”，再交给精修。

**8.3 最小二乘 / SVD 直觉（用内点精修）**
- 有了内点集合后，想让所有点到平面的距离平方和最小。
- 做法上等价于：先把点平移到均值附近，再对协方差做特征分解（或 SVD）。
- 最小特征值对应的特征向量，就是“最垂直”的方向，也就是更稳定的平面法向量。
