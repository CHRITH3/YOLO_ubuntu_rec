# 20260204三种基本姿态判断

本文面向 C++ 初学者，说明“躯干-大腿角度”和“大腿-小腿角度”的计算方法，以及如何用 135° 阈值区分三种基本姿态（tuck / pike / straight）。内容对应现有代码实现。

**目标与入口**

核心实现位于 `get_pose_indemind_left.cpp`。该文件在主循环中已经完成 3D 关键点（相机坐标系）的计算与跟踪，因此本次角度与姿态判断直接基于相机坐标系下的 3D 点。

**1. 关键点与中点定义**

为了保证计算稳定，先用左右髋、左右肩的中点构造躯干向量：

- 髋部中点：`hip_mid = (LHIP + RHIP) / 2`
- 肩部中点：`sh_mid = (LSHO + RSHO) / 2`
- 躯干向量：`trunk = sh_mid - hip_mid`

腿部向量分左右腿分别计算：

- 左腿大腿：`thigh_L = LKNE - LHIP`
- 左腿小腿：`shank_L = LANK - LKNE`
- 右腿大腿：`thigh_R = RKNE - RHIP`
- 右腿小腿：`shank_R = RANK - RKNE`

**2. 角度计算（夹角）**

使用 3D 向量夹角公式计算角度，并转换为度数：

```
angle = arccos( dot(a, b) / (|a| |b|) ) * 180 / π
```

本项目中对应为：

- `trunk-thigh`：`angle(trunk, thigh)`
- `thigh-shank`：`angle(thigh, shank)`

代码中在 `AngleDeg(...)` 内完成归一化、`acos` 与度数转换，并加入了数值保护（`cos` 限制在 [-1, 1]）。

**3. 左右腿合并规则**

- 如果左右腿都有效：取平均值作为最终角度。
- 如果只有一条腿有效：使用该腿角度。
- 如果两条腿都无效：角度与姿态标记为 `Unknown`。

**4. 姿态分类规则（135° 阈值）**

使用平均角度（或单腿角度）做分类：

- `trunk-thigh <= 135` 且 `thigh-shank <= 135` → `Tuck`
- `trunk-thigh <= 135` 且 `thigh-shank > 135` → `Pike`
- `trunk-thigh > 135` → `Straight`

这三个判断在 `ComputePostureMetrics(...)` 中完成。

**5. 界面显示位置**

- **Body Frame Metrics 窗口**：
  - 左右腿角度（度）
  - 平均角度（度）
  - 姿态标签（Tuck / Pike / Straight / Unknown）

- **YOLO Pose 窗口**：
  - 右上角状态栏增加 `Posture: <label>`

这些显示逻辑都在 `get_pose_indemind_left.cpp` 主循环的绘制部分完成，能保证每帧实时刷新。

**6. 关键代码位置速查**

- 角度与姿态计算：`ComputePostureMetrics(...)`
- 角度工具函数：`AngleDeg(...)`
- UI 显示：`Body Frame Metrics` 面板与 `YOLO Pose` 面板文字输出

通过以上步骤，初学者可以清晰理解三种姿态的数学意义，并直接在代码中定位计算与显示的实现。
